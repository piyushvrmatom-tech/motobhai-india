Pre-ride checklist

Documents

  • Driving licence (LL/permanent)
  • Bike RC
  • Insurance (third-party valid)
  • PUC certificate
  • Aadhaar / ID for permits
  • Inner Line Permit (if applicable)

Gear (ATGATT)

  • Full-face helmet (ISI/ECE)
  • CE-armoured jacket
  • Riding gloves
  • Riding pants (kevlar/CE)
  • Ankle boots
  • Rain liner / suit

Bike check

  • Tyre pressure (cold) + tread
  • Chain lube + slack
  • Brake pads + fluid
  • Engine oil level
  • Headlight / indicators / horn
  • Tool kit + puncture kit + 12V pump
